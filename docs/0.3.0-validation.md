# muh todo 0.3.0

Each widget entry now has a 48dp **⏎** button opening the editor for creation
immediately after that physical source line. The date is fixed to the source
entry, and its effective ordered tags are prefilled and editable. Keeping the
tuple writes `^^^`; changing tags writes explicit metadata, and clearing tags
omits metadata. Following existing `^^^` entries naturally inherit the inserted
entry's tuple. Sorting may display the new entry elsewhere; it never changes
the insertion location. Use checkbox still defaults on for new entries.

The editor's Completed and Inherit tags checkboxes are removed. Existing
completion state is retained during edits; toggle it from the widget.
Known-tag suggestions are sorted lexicographically by Unicode code point.
Selecting a tag inserts it at the cursor or replaces selected text, adds one
separator where needed, and removes extra/leading/trailing ASCII spaces.
Selected tag order and duplicate tags are preserved. After insertion the cursor
moves to the end of the entire tag field.
