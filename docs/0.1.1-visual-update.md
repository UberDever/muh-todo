# muh todo 0.1.1 visual update

This hands-on feedback update makes the app, compact editor, widget configuration,
and widget use a dark theme. It keeps the existing typeface and slightly reduces
text sizes; widget task bodies change from 16sp to 14sp. Widget buttons retain
their 48dp touch targets. The displayed application name is now `muh todo`.

The application ID remains `dev.uberdever.muhtodo`. Version code is 2, and the
APK uses the same signing certificate as 0.1.0, so it can be installed as an
update. Existing document selection and widgets remain in app preferences.

The supplied PNG artwork is included unchanged as the launcher icon. An Android
adaptive icon scales and masks it to the launcher's icon shape. The original
bitmap is preserved in the repository.

## Validation

`./gradlew :app:clean :app:testDebugUnitTest :app:assembleDebug :app:lintDebug` passed:

- 84 unit tests, zero failures/errors/skips.
- Android lint: zero errors and 15 warnings. These include the absence of an
  optional monochrome icon; this update uses the supplied full-color artwork.
- APK signature verified; certificate SHA-256 matches 0.1.0:
  `fa9b50183ef19ec98e8510ee736a11d5dceea4e335ec416d3ace87afe10224e9`.
- APK metadata confirms version 0.1.1/code 2 and application label `muh todo`.

Phone appearance still needs hands-on checking. Install the update over the
existing app, open it, and refresh the widget. Check contrast, text size, and the
editor with the keyboard open on GrapheneOS. Sorting controls remain a later
increment.

The existing 0.1.0 Docker archive remains the preserved first checkpoint;
it has not been regenerated for this visual update.
