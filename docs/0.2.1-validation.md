# muh todo 0.2.1

Both widget sorting controls now support off, ascending, and descending.
**Sort by completion** replaces Incomplete first; ascending keeps that behavior,
while descending puts completed tasks and plain entries first. Completion
outranks tags, dates remain newest first, and equal keys retain file order.
Existing widget preferences upgrade with ascending directions.

Checkbox-free entries show an aligned bullet. Tapping the bullet opens the
editor, including after a widget row is reused from a checkbox task.
The tag field hint and invalid-tag validation show `e.g. #buy #cook`.
