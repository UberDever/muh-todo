# muh todo 0.2.0

This iteration adds per-widget completion ordering and tag sorting. Tap the gear
to reopen an instance's settings. Save affects that widget; Cancel leaves its
settings intact. Dates remain newest first, and sorting never rewrites the file.
The minimum resize width is now 160dp so three 48dp header controls fit.

Checkboxes are optional in the Markdown document:

```markdown
### 06.10.26
- [ ] (#a) incomplete task
- [x] (#a) completed task
- (#a) plain entry
- ^^^ another plain entry
```

Plain entries share tags, inheritance, dates, editing, and moves. They have no
widget completion control and sort with completed tasks in incomplete-first
mode. Use checkbox defaults on for new entries; switch it off to create a plain
entry. Ordinary edits and moves preserve checkbox presence. The app's Open in
text editor action was removed; open the file independently in your editor.

## Rebuild this source with the preserved image

Keep the original private 0.1.0 image archive and the new small source snapshot;
no replacement Docker archive is needed for this iteration. The source bundle
also preserves complete Git history. Both source backups exclude signing keys.

After loading `muh-todo-build-0.1.0.tar.gz`, extract the source snapshot and mount
it over the image's historical checkout. This uses the same tools, caches, and
private signing key that passed the offline validation above:

```sh
tar -xzf muh-todo-source-0.2.0.tar.gz
docker run --rm --network=none \
  --mount type=bind,src="$(pwd)/muh-todo-0.2.0",dst=/workspace/muh-todo \
  --entrypoint bash muh-todo-build:0.1.0 \
  -c './gradlew --no-daemon --offline :app:testDebugUnitTest :app:assembleDebug :app:lintDebug; result=$?; chown -R "$1:$2" /workspace/muh-todo; exit "$result"' \
  bash "$(id -u)" "$(id -g)"
```

The APK is then `muh-todo-0.2.0/app/build/outputs/apk/debug/app-debug.apk`.
The image is Linux amd64; other CPU architectures need compatible emulation.
