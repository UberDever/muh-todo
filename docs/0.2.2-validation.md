# muh todo 0.2.2

Widget sorting uses two rows of three equal buttons, with exactly one choice
selected in each row. The selected button is highlighted in the dark theme;
labels wrap and buttons retain a minimum 64dp height.

- Completion: **No sort / Incomplete first / Complete first**.
- Tags: **No sort / a-z and 0-9 / z-a and 9-0**.

The selectors use the existing sorting preferences. Completion still outranks
tags, plain entries sort with completed tasks, dates remain newest first,
and ties retain original file order. No new dependencies were introduced.
