# muh todo 0.4.0

The widget has no top toolbar. Each date header has **+**, opening normal
creation prefilled with that editable date. Widget setup remains required when
adding it. Android's reconfigurable flag lets supporting launchers reopen setup
through **Edit widget**; otherwise recreate the widget to change options.
Moving/resizing alone does not configure. The empty widget opens the app to
create the first entry. Refresh widgets remains in the app for external edits.

Explicit widget tag labels and **Insert a known tag** suggestions share colors
derived from exact UTF-8 tag text. Colors stay stable across process restarts and
changes to the known-tag pool; they do not change Markdown. `^^^` stays neutral.
The finite color space can yield similar colors for some tags.
The inherited-creation button now uses a vector return-arrow icon with its
existing 48dp tap area and accessible description.

Editing an existing entry offers a red **Delete** immediately left of Cancel.
It removes only that physical line and materializes the first inherited
successor's previous tags, including ordered duplicates, without removing date
headings or unrelated Markdown. Further inherited entries retain their tuples.
Deleting uses the existing stale URI/line/date guards and single-operation
ViewModel owner; successful deletion refreshes widgets and closes the editor,
while failure leaves it open. It works even when unsaved fields are invalid.
As with moves, an empty-tag inherited successor with a body beginning reserved
metadata can be unrepresentable explicitly; that write is refused safely.

## Validation

Native `:app:testDebugUnitTest :app:assembleDebug :app:lintDebug` passed: 160 tests,
zero failures/errors/skips; lint zero errors and 20 warnings. The initial
color-distance regression failed as intended during development and passed after
increasing saturation while checking tinted-chip contrast. Offline verification
is pending. Tests cover date routing, required
initial setup/reconfiguration metadata, toolbar removal, error-row hiding,
vector rendering, colored-span recycling and broad dark/tinted-background
contrast, successor preservation, BOM/CRLF/EOF, repeated sections, stale delete
no-write guards and async deletion ownership/failure.

No dependencies or tool versions changed. APK update uses the preserved signing
key. Actual launcher UI and Compose layout/interaction still need the phone
checklist; Robolectric is simulated Android, not a phone validation.
