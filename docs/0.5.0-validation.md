# muh todo 0.5.0

The editor now has a priority picker from 0 to 99. Tap round values directly;
99 is also available. Tap or long-press the exact value to reveal −/+ buttons,
or drag that value horizontally (8dp per step) for exact adjustment.
Vertical scrolling stays available; accessibility offers exact progress and
increase/decrease actions. New entries default to 0; anchored creation prefills
the selected entry's priority, which remains editable.

Priority is the first decimal-only numeric tag, including Unicode decimal
digits. New nonzero priorities go first; new default 0 is omitted. Existing
priority tokens retain their position and raw spelling unless the picker is
used. Editing to zero preserves an explicit #0 in an existing slot. Large
values display/color as 99 without rewriting their text automatically.
Additional numeric tags remain intact; none appear in known-tag suggestions.
When ordinary tags before priority are removed, its insertion position is
limited so another numeric tag cannot accidentally become priority.

Widget tuples now have one deterministic OKLCH color, including inherited
^^^ shorthand. Semantic prefixes select a hue; child tags apply decreasing
perturbations. Priority primarily increases lightness/chroma. Tuple order,
duplicates and exact spelling remain part of color identity. Known semantic
tag suggestions keep their individual primary colors. No global palette,
manual assignments, Markdown color metadata, or dependency changes are needed.
Similar colors can occur, including for unrelated tags; uniqueness is not
guaranteed in a finite color space. Sorting behavior is unchanged.
